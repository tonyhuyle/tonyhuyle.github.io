Remote Desktop Protocol Lab

Built a VirtualBox-based Windows domain lab to practice remote administration, domain connectivity, shared resource management, Group Policy, and remote event log monitoring. The lab simulated common enterprise IT support workflows where administrators manage client systems remotely through RDP, Active Directory, file shares, and Windows management tools.

What I Configured

  • Configured Windows Server and client networking on the same virtual network.
  • Pointed client DNS to the domain controller and joined the workstation to corp.local.
  • Enabled and tested Remote Desktop Protocol access using domain and administrator accounts.
  • Created shared folders and controlled access using Active Directory security groups.
  • Mapped network drives through Group Policy for department-based resource access.
  • Used remote Event Viewer access to review workstation logs without manually logging into the client.

Access Control & File Sharing

Configured department-based access by assigning users to Active Directory groups and granting those groups permissions to specific shared folders. Group Policy was used to automatically map shared drives for users at login, reducing manual workstation setup and improving consistency across the domain environment.

Remote Log Monitoring

Enabled Remote Event Log Management so administrators could connect to client machines by hostname and review system, application, and security logs from the server. This demonstrated a safer and more efficient troubleshooting workflow than opening full RDP sessions for every log review task.

Galveston Fish Recognition Model

Developed a computer vision model capable of identifying common fish species found in the Galveston Bay area. The project leveraged transfer learning with MobileNetV2 to classify images across multiple species while applying modern deep learning techniques to improve accuracy and generalization.

Species Classification

  • Red Drum
  • Black Drum
  • Crevalle Jack
  • Southern Flounder
  • Speckled Trout
  • Southern Kingfish
  • Atlantic Croaker
  • Sheepshead
  • Ladyfish
  • Gafftopsail Catfish

Machine Learning Pipeline

  • Implemented transfer learning using MobileNetV2 as the base architecture.
  • Preprocessed and normalized image datasets for model training.
  • Applied data augmentation techniques to improve model robustness.
  • Utilized dropout layers and batch normalization to reduce overfitting.
  • Implemented learning rate scheduling, early stopping, and adaptive learning rate reduction.
  • Evaluated model performance using training and validation datasets.

Project Outcome

Successfully trained a lightweight image classification model capable of recognizing multiple Galveston-area fish species. The project provided hands-on experience with computer vision workflows, dataset preparation, transfer learning, model tuning, and deep learning deployment concepts.

Skills Demonstrated
